# Sessionbus v0.1.0

Sessionbus v0.1.0 is the first usable local-first release for durable AI
workflow continuity across fragmented engineering tools.

## Highlights

- Rust daemon and `aictx` CLI with SQLite-backed sessions, artifacts, decisions,
  messages, events, and deterministic context packs.
- `aictx setup` for one-command bootstrap of daemon health, bundled adapters,
  dashboard URL, and optional Codex/shell install.
- MCP stdio bridge through `aictx mcp --ensure-daemon`.
- Dashboard for sessions, recent artifacts, integration health, and pack
  rendering/copying.
- Bun TypeScript adapter SDK plus terminal/filesystem sidecar adapters.
- Opt-in passive shell command observation and explicit terminal output capture.
- Bun selftest harness and GitHub Actions CI.

## Install From Source

```bash
PREFIX="$HOME/.local" ./scripts/install.sh
export PATH="$HOME/.local/bin:$PATH"
aictx setup --write --auto-capture --open-dashboard
```

## Verify

```bash
bun run selftest
```

## Privacy

The daemon binds locally, stores data per user, avoids cloud sync in v0, and
captures file/output content only through explicit commands or adapter actions.
